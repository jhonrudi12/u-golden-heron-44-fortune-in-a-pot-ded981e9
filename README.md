One kind, funny fortune for a houseplant, in a single line of at most 120 characters — written for the plant on the windowsill, as if its own future were being told.

## Entry

> This week, a sunbeam will find your tallest leaf, and you will spend the whole afternoon leaning into it like applause.

## How to run

```sh
python3 main.py
```

The program is deterministic and uses no network. It writes the fortune to `/output/entry.txt` and prints it.
